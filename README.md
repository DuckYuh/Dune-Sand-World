# 🎮 [Tên Game Của Bạn]

Một trò chơi 2D được phát triển bằng **C++** và **Cocos2d-x**.  
Dự án được tạo với mục tiêu học hỏi công nghệ và luyện tập lập trình game.

---

## 🚀 Tính năng chính
- ⚔️ Gameplay: Sử dụng mũi tên để điều khiển Player di chuyển, Z để bắn, Y để nhảy
- 🎨 Đồ họa: 2D sử dụng Cocos2d-x Sprite system
- 🔊 Âm thanh: hỗ trợ hiệu ứng âm thanh và nhạc nền
- 🧠 Logic: Player va chạm Bullet sẽ mất máu, Bullet va chạm Enemy sẽ hạ gục Enemy.

---

## 🛠️ Công nghệ sử dụng
| Thành phần | Mô tả |

| **Ngôn ngữ** | C++ |
| **Game Engine / Framework** | Cocos2d-x |

## 📦 Cài đặt & Chạy Game

### Build Game:

1/ mkdir build

2/ cd build

3/ cmake .. -G "Visual Studio 17 2022" -A Win32

### Run Game:

1/ cd build

2/ Mở file btl3_game.sln

3/ Chạy Local Window Debug để run game

3.1/ Sau khi Chạy Local Window Debug có thể run game bằng cách cd bin/btl3_game/debug chạy file btl3_game.exe
